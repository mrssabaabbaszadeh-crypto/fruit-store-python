# 🍎 Fruit Store Management System

A simple Python-based fruit store management system with shopping cart functionality, inventory management, and payment processing.

## 📋 Features

- **Product Management**: View products with ID, name, price, stock, and description
- **Shopping Cart**: Add, remove, update quantities of items
- **Discount System**: Automatic 10% discount on all purchases
- **Payment Processing**: Cash and bank card payment options
- **Invoice & Receipt**: Detailed invoices and payment receipts
- **Inventory Updates**: Automatic stock reduction after purchase
- **Help & Support**: Built-in help guide and contact information

## 🚀 How to Run

```bash
python fruit_store.py


1. Select "Show Products" to see available items
2. Choose "Add to Cart" and enter product code 101
3. Enter quantity (e.g., 3)
4. Repeat for more products
5. Select "Show Invoice" to see total with 10% discount
6. Choose "Payment & Finalize" to complete purchase
7. Select payment method (cash or card)
8. Receive receipt and updated inventory
